📖 Comment obtenir un jeton ? (5 minutes, pas à pas)
  1. Sur github.com, cliquez votre avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nom : « Site Hilaire » · Expiration : 1 an.
  3. Repository access : Only select repositories → sélectionnez le dépôt du site.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. Cliquez Generate token, copiez la clé et collez-la ci-dessus.

💡 Avec un jeton « classic », cochez simplement la case repo entière. Si GitHub répond « Resource not accessible by personal access token », le jeton n’a pas le droit d’écriture : vérifiez l’étape 4 et que le bon dépôt est sélectionné.
